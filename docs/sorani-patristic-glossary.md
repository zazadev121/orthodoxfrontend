# Sorani Orthodox translation terminology

Use these terms consistently for newly translated patristic passages. Existing editorial translations are not automatically rewritten.

| English | Sorani |
| --- | --- |
| Word (Logos, John 1) | وشە |
| Only-begotten Son | تاقە کوڕی تاکخراو |
| Church Fathers | باوکانی کڵێسا |
| Saint | پایەپیرۆز |

Preserve the distinction between the eternal begetting of the Son and the creation of creatures. Do not translate a quotation as a paraphrase. New translations require linguistic and theological review.
